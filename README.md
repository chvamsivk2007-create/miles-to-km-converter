# Miles to Kilometres Converter 🛣️➡️📏

Python GUI project that converts miles into kilometres using the **Tkinter** library.

---

## 📖 Description
- Simple GUI with input field for miles
- Converts miles to kilometres (1 mile = 1.609 km)
- Displays result instantly on button click

---

## 📂 Features
- Clean Tkinter interface
- Real‑time conversion
- Beginner‑friendly project showcasing GUI programming
